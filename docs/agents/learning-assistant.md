# 学习助手

自学通 内置的 `ChatbotAgent` 当前定位为个人学习助手。它会围绕用户的个人工作区、知识库和对话上下文，帮助维护学习画像、识别已有学习计划，并推进新的学习主题。

## 工作区文件约定

学习助手使用当前用户 workspace 下的固定 Markdown 文件保存学习计划：

| 文件 | 用途 |
|------|------|
| `learning-profile.md` | 用户学习画像，例如目标、背景、偏好和长期计划 |
| `learning-plans/index.md` | 总计划索引，用 Markdown 表格登记所有子计划 |
| `learning-plans/<topic>.md` | 单个主题的学习计划、阶段目标和推进记录 |

系统会确保用户 workspace 的基础文件存在。学习助手读取和写入计划时，仍通过智能体文件工具走沙盒虚拟路径。

## 空会话入口

当用户打开空对话时，前端会调用：

```http
GET /api/chat/learning/overview
```

该接口只读取当前用户 workspace 中的学习计划概览，返回：

- `profile_exists`：是否存在学习画像文件
- `index_exists`：是否存在总计划索引
- `plans`：从 `learning-plans/index.md` 表格解析出的计划列表
- `new_topic_prompt`：开始新主题时自动填入输入框的提示前缀

如果存在历史计划，空会话会展示计划列表。点击已有计划会把继续学习的指令填入输入框；点击“开始新的学习主题”会引导用户先描述新主题。

## 新主题流程

学习助手的提示词要求新主题先匹配历史计划，再决定是否创建新计划：

1. 先检查 `learning-plans/index.md` 中是否已有相同或相近主题。
2. 如果已有计划，优先继续推进原计划。
3. 如果是新主题，先根据用户目标推荐候选知识库。
4. 创建或更新计划前，需要让用户确认知识库选择。
5. 确认后再写入 Markdown 学习计划。

这个流程的目的不是自动生成一堆文件，而是让学习计划和知识库来源保持可追踪。

## 树状对话与分支学习

学习助手支持从已有消息创建树状对话分支，适合在保留原学习路径的同时探索不同解释、练习方向或复习方案。

使用方式：

1. 在已有用户消息或助手消息上选择“从此处分支”。
2. 系统创建一个新的子线程，并在对话历史侧栏中按父子关系显示。
3. 子线程首次提问时继承所选消息之前的用户和助手上下文；之后的内容只写入子线程。
4. 原线程保持不变，可以随时返回继续原来的学习路径。

分支关系通过线程元数据保存，分支点由用户明确选择，不会由系统自动移动或合并。当前实现是树状线程分支，不包含多父合并、引用边或画布编辑。

## 维护建议

- 总计划索引必须保留 `主题`、`文件路径`、`状态`、`最近更新时间` 四列，否则概览接口无法识别计划。
- 子计划建议使用清晰的阶段标题、检查项和引用资料，方便后续继续学习。
- 如果手动编辑 workspace 文件，保持文件路径和索引表一致。
