# 项目简介

自学通是一个面向个人长期学习的自学平台，帮助你整理课程资料、沉淀笔记、追踪学习进度，并通过 AI 辅导推进学习计划。该平台基于 LangGraph v1、Vue.js 3、FastAPI 和 LightRAG 构建，融合 RAG、知识图谱和个人工作区能力，让零散资料逐步变成可检索、可复盘的知识体系。

## 设计理念

项目的设计目标是为个人学习者提供一个易于上手、可持续使用的 AI 自学空间。我们坚持以下原则：

- **技术栈简洁**：选择主流且成熟的技术，降低学习和维护成本
- **MIT 开源协议**：完全开源，允许自由使用和二次开发
- **容器化部署**：通过 Docker Compose 管理，简化部署流程

## 技术架构

| 层级 | 技术 | 用途 |
|------|------|------|
| 前端 | Vue.js 3, Vite, Ant Design Vue | 现代响应式 UI 框架与组件库 |
| 状态管理 | Pinia | 前端集中式状态管理 |
| 后端 API | FastAPI, Uvicorn | 高性能异步 Python Web 框架 |
| Agent 框架 | LangGraph v1 | 声明式 Agent 编排与状态管理 |
| 知识库 | LightRAG, PostgreSQL/pgvector | 基于向量存储的 RAG 实现 |
| 图数据库 | Neo4j | 知识图谱存储与查询 |
| 文档处理 | Docling, Scrapling, PaddleX, RapidOCR | 多格式文档解析、网页读取与 OCR |
| 任务队列 | Redis, PostgreSQL Workers | 异步任务处理 |
| 对象存储 | MinIO | 文件与文档存储 |
| 关系型数据库 | PostgreSQL | 元数据与用户数据持久化 |
| 部署 | Docker, Docker Compose | 容器化部署与编排 |


## 核心能力

自学通的核心能力不在于“把大模型接进来”，而在于把 **学习资料、知识库/RAG、知识图谱、AI 辅导和个人工作区** 放进同一套系统里，并让它们围绕长期学习目标协同工作。

### 1. 面向个人学习的 AI 辅导

自学通基于 LangGraph v1 提供智能体能力，不只是一个固定问答入口，而是能够结合个人资料、工作区文件和学习计划来回答问题、总结重点、拆解难点并推进下一步学习。

这一层是项目的控制中心，决定了模型如何调用工具、如何访问知识、如何接入文件系统以及如何与其他子智能体协作。

### 2. 知识库与 RAG 一体化能力

自学通 提供完整的知识入库链路，而不是只做检索接口封装。文档从上传开始，会经过解析、分块、向量化、检索配置和评估等阶段，最终成为 Agent 可直接调用的知识来源。

将组织的文档转换为智能对话助手。上传 PDF 手册、技术规格、政策文档和培训材料，以创建可搜索、具备推理能力的知识库，员工可以使用自然语言查询。
该系统能够理解复杂的问题，并提供带有来源引用的上下文感知答案。

除了本地文件，知识库也支持网页 URL 读取。系统会发现同域页面，按内容相似度排序，并在入库前生成可预览、可编辑的 Markdown 清洗结果，避免直接把导航、页脚和广告噪声写入知识库。


### 3. 知识图谱参与推理，而不只是展示

自学通 的知识图谱能力不是孤立的可视化模块，而是和知识库、Agent 推理链路联动的。
构建需要理解实体之间关系的应用程序。LightRAG 自动从文档中提取实体和关系，创建系统可以查询以进行复杂推理任务的知识图谱。
以标准格式上传现有图谱数据，或使用自动构建功能从非结构化文本生成图谱。

### 4. 面向生产落地的文档理解与平台能力

为了让知识真正可用，自学通 集成了 Docling、PP-Structure-V3、RapidOCR 等解析能力，覆盖 PDF、Office、Markdown、图片等常见格式，解决原始资料进入系统前的结构化处理问题。

在此基础上，平台还补齐了业务落地常用的工程能力，例如：

- 个人工作区和智能体产物预览
- 内容审查与守卫能力
- 文件管理、任务中心与运行监控
- 学习计划概览和学习助手入口
- Docker Compose 部署与热重载开发


## 适用场景

自学通适用于以下场景：

- **课程自学**：整理课程资料、笔记和练习记录
- **考试复习**：围绕知识点建立复习计划并追踪薄弱项
- **资料阅读**：把 PDF、网页和文档沉淀为可检索的个人知识库
- **主题研究**：用知识图谱梳理概念关系和资料脉络
- **长期成长记录**：保存阶段目标、学习成果和复盘内容
